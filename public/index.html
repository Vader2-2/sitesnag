FAQ

    
How do I open the downloaded site?
Unzip it and open index.html in your browser. If parts of the page are missing (big sites like GitHub need their JavaScript), double-click Open site.bat instead, or run node serve.js on Mac/Linux, to view it through the included mini web server.

    
What if the site is down or has changed?
Choose “Latest working Wayback snapshot”, or paste a web.archive.org/web/… link. SiteSnag checks the Internet Archive's most recent captures, newest first, skips broken ones, and rebuilds the site from the first one that loads. In the default mode this happens automatically when the live site can't be reached.

    
Does it work with React / single-page apps?
It saves what the server sends. Sites that build all their content with JavaScript at runtime may need an internet connection for their API calls to work.

    
Can I download any site?
Only download sites you own or have permission to copy, and respect the site's terms and copyright.
